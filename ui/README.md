# UI

React frontend for The Lore.

**Owner:** Aayusha (interaction & navigation)

## Responsibility

- Take user input (a need, e.g. "summarize meeting notes")
- Call the matching backend
- Display ranked skill results
- Let users open a skill and understand how to use it

## Key flow

```
SearchBar  →  ResultsList  →  SkillDetail
```

## Run (later)

```bash
npm install
npm run dev
```
