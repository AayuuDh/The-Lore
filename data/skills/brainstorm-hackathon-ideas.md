## Instructions

Given a problem space, user group, or theme, generate multiple creative but practical hackathon or prototype ideas. Focus on novelty, feasibility, and user value. Format the output as a concise bullet list, with each idea described in one line.

## Example

**Input:** We want hackathon ideas that help interns be more productive at work.

**Output:**

- AI onboarding guide that answers intern questions based on team docs and FAQs
- Meeting recap tool that turns notes into action items and follow-ups
- Networking assistant that suggests personalized coffee chat questions and follow-up messages
- Internship dashboard that tracks goals, wins, blockers, and learning progress
