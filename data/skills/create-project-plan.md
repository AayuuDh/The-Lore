## Instructions

Break down the project into clear phases and tasks. Include logical ordering, key milestones, and short descriptions for each step. Keep the plan structured and easy to follow.

## Example

**Input:** Build a website for a small business

**Output:**

1. Define requirements
2. Create wireframes
3. Develop frontend and backend
4. Test functionality
5. Launch website
