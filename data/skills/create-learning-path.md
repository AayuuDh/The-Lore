## Instructions

Given a skill or topic to learn, create a practical learning plan with manageable steps, suggested milestones, and a simple progression from beginner to more confident use. Keep the plan realistic and concise.

## Example

**Input:** I want to learn Git well enough to contribute confidently during my internship.

**Output:**

Week 1: Learn basic commands like clone, pull, add, commit, and push
Week 2: Practice branching, merging, and resolving simple conflicts
Week 3: Use Git in a real project workflow with pull requests and reviews
Goal: be comfortable making changes and collaborating through version control
